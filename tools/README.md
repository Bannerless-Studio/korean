# tools/ — Korean pack builder inputs (dev/agent notes)

This directory holds the data Korean owns: hand-maintained overrides and
generated-sentence source text, plus the shim that calls the shared builder in
`engine/tools/packbuilder`, and the reports the builder writes back. Korean-specific
linking rules (the eojeol analyser, particle handling, number series, homograph
disambiguation, honorific mapping) are code, not data, and live in
`engine/tools/packbuilder/langs/ko.py`.

## Files

- `build_pack.py` — **glue.** Shim that runs
  `python3 -m packbuilder build --lang ko --repo .` against `engine/tools` (or
  `PACKBUILDER_PATH` if set).
- `requirements.txt` — **config.** `engine/tools/packbuilder/requirements.txt` plus
  the spaCy Korean model (`ko_core_news_sm`).
- `gloss_overrides.json` — **hand-maintained.** Gloss fixes keyed `"lemma|pos"`
  (cut-off and definitional glosses, replaced ideophone/determiner glosses).
- `gloss_display.json` — **hand-maintained.** 15 display-only gloss additions, applied
  at build so the English also shows the sense or form a passage uses (e.g. 안 "not;
  inside", 나다 "to come out ... (화가 나다: to get angry)").
- `forced_a1.txt` — **hand-maintained.** A1 core list forced into A1 (closed sets like
  both number series, days/months/colours live in code, in `langs/ko.py`).
- `mispaired.tsv` — **hand-maintained.** Tatoeba pairs dropped at every level: the
  English translates a different sentence, a misspelt word changes the meaning
  (막을까 for 먹을까), or the Korean is ungrammatical. Format: Korean, tab, English.
  The non-standard-spelling class (너가, -어죠, 할께 ...) is dropped separately by
  rule (`NONSTANDARD_KO` in `langs/ko.py`).
- `generated_sentences.tsv` — **hand-authored input.** 1,692 sentences written for
  this pack (word, Korean, English) where Tatoeba had too few usable sentences;
  append-only (order sets ids), tagged `"src": "gen"` in the output.
- `passages_src.json` — **hand-authored input.** Source text for the 60 reading
  passages (`pack/passages.json`), rebuilt with `packbuilder passages`.
- `id_map_v1.json` — **generated, frozen.** `"lemma|pos"` -> word id map; never
  hand-edit or renumber, it's what keeps learner progress across rebuilds.
- `REPORT.md` — **generated** (manual QA-verdict section preserved across rebuilds).
  Tagging stats, word-selection funnel, level-band counts, seeds, engine-bump log.
- `REPORT_passages.md` — **generated.** Per-passage coverage, level-budget and
  question counts for the 60 reading passages.

## Repo layout

```
pack/
  pack.json         trainer config (levels, placement test, function words)
  words.json        2000 word entries
  sentences.json    example sentences, each tagged with the word ids it covers
  attribution.json  per-source licence + contributor attribution
  pack.js words.js sentences.js   generated by engine/tools/jsonify_pack.py (committed, never hand-edited)
engine/             git submodule -> vocab-engine (UI, drill logic, build/validate tools,
                    tools/packbuilder = the shared pack builder, langs/ko.py = Korean rules)
tools/              see file list above
build.sh            builds index.html (the self-contained trainer) from pack/ + engine/
check.sh            packbuilder check + engine validator + stale-build guard, all in one
index.html          built trainer
```

## Full rebuild from a clean checkout

```
git clone --recurse-submodules <this repo>
# or, if already cloned: git submodule update --init

cd korean
python3 -m venv .venv
source .venv/bin/activate
pip install -r tools/requirements.txt

python3 tools/build_pack.py          # rebuild pack/{pack,words,sentences,attribution}.json + tools/REPORT.md
python3 engine/tools/jsonify_pack.py pack   # regenerate pack/*.js from the .json
./build.sh                           # build index.html
./check.sh                           # pack checks + engine validation + stale-build guard
```

The `engine` submodule is pinned to a vocab-engine commit that already contains
`tools/packbuilder/langs/ko.py`, so `build.sh` and `check.sh` work against
`engine/tools` with no `PACKBUILDER_PATH` override needed.

Sources download once into `.cache/` (gitignored). The build is deterministic, so
re-running from cache reproduces byte-identical `pack/*.json`. spaCy tags the 12,000
Tatoeba sentences with an English translation once, under a minute on a laptop CPU;
the result is cached under `.cache/derived/`. Editing `tools/generated_sentences.tsv`
changes the corpus, so the next build tags again. QA helpers run with
`PYTHONPATH=engine/tools python3 -m packbuilder {check,scan,sample} --lang ko --repo .`.

## Korean rules (see `langs/ko.py` for the code)

The builder's Korean module handles what the shared pipeline cannot guess.

- **An eojeol is analysed, not looked up.** spaCy splits text into spaced words
  (eojeol) and gives each a tag class; the tag is a hint, never a verdict. The
  Korean module's analyser then reads each eojeol as one of:
  - a noun plus a particle chain (친구한테는 is 친구 + -한테 + -은/는);
  - a conjugated verb or adjective — endings generated for regular stems; irregular
    stems (듣다 들어, 춥다 추워, 알다 아세요) come from Wiktionary's conjugation
    tables;
  - a predicative noun + 하다 or 되다;
  - a noun + the copula -이다;
  - a closed-set word.
  Particles and the copula are linked but don't count toward sentence length.
- **Particles are words.** Core particles (-이/가, -은/는, -을/를, -에, -에서,
  -(으)로, -와/과, -도, -만, -까지, -부터, -한테, -에게, -처럼, -보다, -마다,
  -밖에, -씩 and others) are A1 entries named by both allomorphs. A particle written
  apart from its noun (게임 이나) is still the particle.
- **Numbers come in two series.** Sino-Korean (일 to 십, 백, 천, 만) and native
  (하나 to 열, 스물) are separate words. A numeral spelling is the number only
  before a counter of its own series, or when the tagger reads it as a numeral: 삼
  년 and 두 명 are numbers, 이 사람 ("this person") and 네가 한 일 ("what you did")
  are not. 네 before a noun is "your" unless the translation says "four"; 이 before
  a Sino-Korean counter is "two" only when the translation counts that unit.
- **Homographs follow the translation.** Nouns with two common meanings (눈
  "eye"/"snow", 배 "belly"/"ship", 다리 "leg"/"bridge") and verbs sharing a spelling
  (살: 사다/살다; 들어: 듣다/들다; 걸어: 걷다/걸다; 팔: 팔다/파다) link the reading
  whose English appears in the translation. A meaning taking ~10% or less of a
  spelling's uses (말 "horse", 차 "tea", 밤 "chestnut") is not a separate word and
  that spelling links nothing.
- **Spoken forms count toward their standard word.** 이거/그거/저거 link
  이것/그것/저것; 거야/꺼야 link 것 + -이다; 맘 links 마음; 뭔지 links 뭐.
- **Grammar patterns link nothing.** -고 나서 "after", -ㄹ지도 모르다 "might" and
  -에도 불구하고 "despite" are grammar, not vocabulary; they link no word.
- **Honorific/humble verbs are taught through the plain verb.** 드리다 links 주다,
  드시다 links 먹다 (the shared lexicon drops Wiktionary form-of senses). 계시다
  keeps its own entry.
- **Font.** `pack.json` sets `fontFamily` to "Apple SD Gothic Neo", "Noto Sans KR",
  "Malgun Gothic", sans-serif and `fonts` to Noto Sans KR, which the engine applies
  to every element marked `lang="ko"`.
- **Typing** (`typing: {caseSensitive: false, accents: lenient, strictFromLevel:
  null}`): case doesn't apply to Hangul and there are no combining marks for lenient
  accents to fold, so lenient is a no-op that stays on at every level. Affix
  alternates (engine 93f77a2): typing a particle accepts the bare form without its
  leading hyphen (-이다 → 이다), the slash form and each side alone for a slash alt
  (-이/가 → 이/가, 이, 가), and both the parens-dropped and group-dropped forms for
  a parenthetical alt (-(으)로 → 으로, 로). The same engine's collision guard over
  lenient folds is a no-op for Korean (no colliding pair currently).

## QA history and fix rounds

- **v1 QA.** Stratified sample of 180 words (seed 51) + 90 sentences (seed 52): 178/180
  words had a clean, correct primary sense (two gloss defects found and fixed, plus
  one more, 문자, found by auditing all 2000 glosses for the same defect class);
  560/562 sentence links right (one wrong link — 싸다 "cheap" vs "to poop" — fixed by
  replacing the sentence; the other, spaced 만 하다, correctly links 하다).
- **Fix round (v1.1, 2026-09-25).** Wrong-link and level classes fixed by rule in
  `langs/ko.py`: a frequent noun/numeral spelled like a verb form (사고, 신고는, 둘
  중, 하나) links the noun when English doesn't attest the verb, and 들어/들었
  default to 들다; determiners 어떤/이런/그런/저런/아무런 are words of their own;
  nominal alts are only the word plus a particle chain or copula (light verb,
  compound and bare-contraction spellings are no longer alts); English-capitalised
  names stop their Korean spelling from linking a common noun (도쿄, 대만); a
  modifier needs a following noun (이를 닦다, 그를 믿다 are noun+particle; 화가 난
  것 is 나다); -기 after a verb stem is the nominaliser (배우기 is 배우다), 도시다
  is 도시+copula; Wiktionary's ideophone "nouns" (딱, 점점, 깜짝) are adverbs;
  definitional glosses replaced (그래서, 열심히, 마을 and ~50 more). Fresh samples
  after the round (seed 71/90 words, seed 72/90 sentences): 90/90 correct both ways.
- **Round 3 (v1.2, 2026-09-25).** Bare 거 always links 것 (never 거기); an alt is
  refused when a longer headword or name covers the eojeol (대만은, 대대로 aren't
  대+particles); 한 after a modifier is the noun "as long as" (가능한 한); a fused
  안+verb follows the translation (안들어요 "don't cut" is 들다); 다시는 is 다시+는.
  졸리다, 이빨, 베개, 습관, 여우 replaced five low-rank NIKL 고급 abstractions (공공,
  경향, 관점, 이래, 수면). Seed-92 sample: 90/90 sentences with every link right.
- **Conjugation check.** 20 sentences with conjugated verbs: all 35 verb forms
  linked to their lemma, including the ㅂ, 르, ㄹ and 으 irregulars. Top 300 words
  have no wrong part of speech and no non-lemma headword. Every closed set is
  complete at A1 (both number series, days, months, colours, pronouns, particles,
  time words, greetings). 96.5% of word links (particles aside) can be blanked in a
  gap drill as a whole word or a listed form.
